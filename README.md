# Terminal

A small terminal emulator written in Python.

## Features

- Custom username and computer name
- Virtual directory navigation
- File and directory management
- Colored command list
- Linux commands through `subprocess`
- Modular command system

## Commands

| Command | Description |
|---|---|
| `$help` | Show available commands |
| `$time` | Show the current time |
| `$date` | Show the current date |
| `$time&date` | Show the current time and date |
| `$cd <directory>` | Change the current directory |
| `$mkdir <directory>` | Create a directory |
| `$pwd` | Show the current directory |
| `$ls` | Show directory contents |
| `$cp <source> <destination>` | Copy a file or directory |
| `$rm <file/directory>` | Delete a file or directory |
| `$exit` | Exit the terminal |
